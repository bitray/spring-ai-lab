# 公司薪酬管理细则

薪酬管理遵循合法合规、公平合理、按劳分配的原则。公司所有员工的薪酬由以下四部分构成：基本工资、岗位工资、绩效工资和各项津贴。其中基本工资是员工劳动合同中约定的固定月薪，用于计算病假、事假、年假等各类假期及法定节假日加班的工资基数；岗位工资根据员工所在职级确定，随职级晋升或调整而变动；绩效工资与员工月度及季度绩效考核结果挂钩，考核结果分为优秀、良好、合格、待改进四档，分别按绩效工资基数的120%、100%、80%、50%发放；津贴包括交通补贴、通讯补贴、餐补和住房补贴，具体标准参照公司发布的《员工福利手册》。员工的月应发工资为基本工资、岗位工资、绩效工资与各项津贴之和，公司于每月15日发放上月工资，若遇法定节假日则提前至节前最后一个工作日发放。工资发放应当通过员工本人实名银行账户转账，严禁代领、冒领，员工对工资明细有异议的，可在收到工资条后五个工作日内向人力资源部提出书面复核申请。

关于病假工资的计算，公司规定如下：员工每年累计病假不超过30天的，病假期间工资正常发放，即全额发放基本工资，岗位工资与绩效工资按正常出勤标准核算；员工每年累计病假超过30天的部分，按基本工资的80%发放，绩效工资按实际出勤天数折算，岗位工资照常发放。病假工资的计算基数为员工的基本工资，日工资标准按基本工资除以21.75天（法定月计薪天数）计算。举例说明：员工王某某的基本工资为8000元，2026年累计请病假35天，其中前30天工资正常发放，即8000元全额发放；超过30天的部分为5天，按基本工资的80%计算，日工资为8000除以21.75约等于367.82元，5天的病假工资为367.82乘以5再乘以80%约等于1471.26元，因此王某某该月病假工资合计为8000元加上1471.26元，即9471.26元。再举例说明：员工李某某的基本工资为12000元，2026年累计请病假45天，前30天正常发放12000元，超过部分为15天，日工资为12000除以21.75约等于551.72元，15天按80%计算为551.72乘以15乘以80%约等于6620.7元，李某某该月病假工资合计为12000元加上6620.7元，即18620.7元。

员工申请病假应当遵守以下流程：员工因病需要休假的，应在病假开始前通过OA系统提交病假申请，说明请假天数与病因，并上传二级甲等及以上医院出具的诊断证明。确因突发疾病无法提前申请的，可先通过电话或企业微信向直属领导报备，并在返岗后两个工作日内补交申请材料。连续病假超过3天的，需要额外提交住院证明或复查报告，人力资源部有权要求员工到指定医院进行复核，复核费用由公司承担。员工病假期间应当保持通讯畅通，因病情变化需要延长病假的，应当在原病假到期前一个工作日提交延期申请。病假期间公司不得解除劳动合同，但员工提供虚假病假证明的，公司有权依据《员工手册》相关规定给予纪律处分，情节严重的可依法解除劳动合同并追究相应责任。员工病假跨月的，病假天数按自然日连续累计计算，不因跨月而重新计算。员工在同一自然年度内病假与事假合并计算的，病休总天数超过180天的，公司有权根据法律规定与员工协商安排长期医疗期，医疗期工资标准按当地最低工资标准的80%发放，具体参照国家和地方相关法律法规执行。

## 附则

- 本细则自发布之日起施行，由人力资源部负责解释。
- 本细则与公司其他制度不一致的，以本细则为准。
- 员工可通过OA系统薪资查询模块查询本人工资及病假工资明细。
