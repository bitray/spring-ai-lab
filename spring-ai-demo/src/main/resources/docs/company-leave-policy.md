# 公司请假制度

## 年假规定
- 入职满1年不满10年的员工，每年享有5天带薪年假。
- 入职满10年不满20年的员工，每年享有10天带薪年假。
- 入职满20年的员工，每年享有15天带薪年假。
- 年假必须在当年内使用完毕，不可跨年累积。
- 年假需提前3个工作日向直属领导申请。

## 病假规定
- 病假需提供二级甲等及以上医院的诊断证明。
- 每年累计病假不超过30天的，工资正常发放。
- 超过30天的部分，按基本工资的80%发放。
- 连续病假超过3天的，需要提交住院证明或复查报告。

## 事假规定
- 事假为无薪假期，按天扣除当日工资。
- 每月事假累计不得超过3天。
- 事假需提前1天在OA系统中提交申请。
- 紧急事假可当天电话报备，但需在2个工作日内补交申请。

## 婚假与产假
- 婚假：法定3天，晚婚（男25岁/女23岁以上）额外加7天，共10天。
- 产假：女员工法定98天，难产加15天，多胞胎每多一个加15天。
- 陪产假：男员工享有15天陪产假。
- 婚假和产假期间工资照常发放。
