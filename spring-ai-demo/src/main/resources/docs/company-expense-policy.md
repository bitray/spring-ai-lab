# 报销管理制度

## 差旅报销
- 交通标准：普通员工限高铁二等座或经济舱，部门经理及以上可乘坐商务座或公务舱。
- 住宿标准：一线城市每晚不超过500元，二线城市不超过350元，三线城市不超过250元。
- 出差补贴：每天100元餐补 + 50元交通补贴，无需提供发票。
- 差旅报销需在出差结束后5个工作日内提交。

## 餐饮报销
- 商务宴请：人均不超过200元，需注明参与人员和事由。
- 团队聚餐：每季度每人100元额度，需部门经理审批。
- 加班餐：工作日加班至20:00以后，可报销50元以内的晚餐费用。

## 报销流程
1. 在OA系统中填写报销单，上传发票照片。
2. 直属领导审批（金额超过2000元需总监审批）。
3. 财务部审核发票合规性。
4. 审核通过后，报销款项在每月15日和30日统一打款。

## 发票要求
- 必须为增值税普通发票或专用发票。
- 发票抬头必须为公司全称："星辰科技有限公司"。
- 电子发票需打印后粘贴在报销单上。
- 超过3个月的发票不予报销。
